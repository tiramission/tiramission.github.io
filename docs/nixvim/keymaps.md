# 快捷键

使用 **Space** 作为 Leader 键 (`<leader>` = 空格)

## Telescope 搜索

| 快捷键 | 描述 |
|--------|------|
| `<leader><space>` | 查找项目文件 |
| `<leader>s/` | 全局搜索 |
| `<leader>s;` | 命令历史 |
| `<leader>s:` | 命令历史 |
| `<leader>sb` | 搜索 Buffer |
| `<leader>sC` | 搜索命令 |
| `<leader>sD` | 工作区诊断 |
| `<leader>sH` | 搜索高亮组 |
| `<leader>sK` | 搜索快捷键 |

## UI 界面

| 快捷键 | 描述 |
|--------|------|
| `<leader>u` | UI 相关操作 |

## 窗口操作

| 快捷键 | 描述 |
|--------|------|
| `<leader>w` | 窗口操作 |

## 退出操作

| 快捷键 | 描述 |
|--------|------|
| `<leader>q` | 退出操作菜单 |
| `<leader>qq` | 直接退出 |
| `<leader>q!` | 强制退出 |
| `<leader>qx` | 保存并退出 |
